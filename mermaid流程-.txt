
# Life MVP 页面流程图

```mermaid
flowchart TD

    B --> C[日程页]
```

# 2. 首页主流程

首页是 MVP 的核心页面。

```mermaid
flowchart TD
    A[进入首页] --> B[读取当天日程数据]
    B --> C[按时间轴排序]
    C --> D[检测时间冲突]
    D --> E[生成时间轴显示单元]
    E --> F[检测 AI 提醒]
    F --> G{是否有重要提醒}

    G -->|有| H[显示 AI 提醒卡片]
    G -->|无| I[隐藏 AI 提醒卡片]

    H --> J[展示今日时间轴]
    I --> J

    J --> K[用户操作]

    K --> K1[点击 + 新建日程]
    K --> K2[输入自然语言]
    K --> K3[点击日程卡片]
    K --> K4[点击冲突组]
    K --> K5[点击 AI 提醒卡片]
    K --> K6[点击 L 生活管家]
    K --> K7[点击 M 预设模式]
```

首页包含这些区域：

| 区域    | 内容                           |
| ----- | ---------------------------- |
| 顶部区域  | Life 标题、日期、L 生活管家入口、M 预设模式入口 |
| AI 区域 | 最高优先级 AI 提醒卡片                |
| 时间轴区域 | 今日所有日程、冲突组、进行中状态             |
| 底部输入区 | 自然语言输入框、语音按钮、“+”按钮           |
| 底部导航  | 日程、计划、统计、日记、我的               |

# 3. 手动新建日程流程

```mermaid
flowchart TD
    A[首页点击 +] --> B[进入新建日程页]
    B --> C[初始化日程草稿]

    C --> D[填写日程名称]
    C --> E[选择日期]
    C --> F[选择开始时间]
    C --> G[填写持续时间]
    C --> H[选择优先级 P0/P1/P2]
    C --> I[选择重复频率]
    C --> J[填写备注]

    D --> K[点击保存]
    E --> K
    F --> K
    G --> K
    H --> K
    I --> K
    J --> K

    K --> L{字段是否合法}

    L -->|否| M[提示补充或修改字段]
    M --> B

    L -->|是| N[计算结束时间]
    N --> O[检测是否与已有日程冲突]

    O -->|无冲突| P[显示确认添加卡片]
    O -->|有冲突| Q[显示冲突提示卡片]

    P --> R{用户确认添加}
    Q --> S{用户选择}

    S -->|仍然添加| R
    S -->|查看调整建议| T[打开冲突调整二级菜单]
    S -->|修改时间| B

    R -->|确认| U[保存日程]
    R -->|取消| B

    U --> V[重新生成当天时间轴]
    V --> W[检测 AI 提醒]
    W --> X[返回首页]
```

# 4. 自然语言输入流程

```mermaid
flowchart TD
    A[首页输入自然语言] --> B[点击发送]
    B --> C[本地规则解析]

    C --> D{解析置信度}

    D -->|高| E[生成日程草稿]
    D -->|中| F[生成可修改草稿]
    D -->|低| G[交给外部 AI 或提示补充]

    G --> H{外部 AI 是否成功}
    H -->|成功| E
    H -->|失败| I[进入手动补全流程]

    E --> J{字段是否完整}
    F --> J

    J -->|不完整| I
    J -->|完整| K[显示确认卡片]

    I --> L[新建日程页，自动填入已识别信息]

    K --> M{用户选择}
    M -->|确认添加| N[保存日程]
    M -->|修改一下| L
    M -->|取消| O[返回首页]

    N --> P[重新生成时间轴]
    P --> Q[检测冲突]
    Q --> R[检测 AI 提醒]
    R --> S[返回首页]
```

自然语言输入的页面结果有 4 种：

| 输入结果  | 页面表现          |
| ----- | ------------- |
| 解析成功  | 展示确认添加卡片      |
| 缺少字段  | 进入补全流程        |
| 有时间冲突 | 展示冲突提示        |
| 解析失败  | 提示用户换种说法或手动添加 |

# 6. 时间冲突流程

```mermaid
flowchart TD
    A[时间轴生成完成] --> B[检测日程是否重合]

    B --> C{是否存在重合}

    C -->|否| D[普通时间轴展示]
    C -->|是| E[建立冲突分组]

    E --> F{冲突组内事件数量}

    F -->|1 个| D
    F -->|2 个| G[并列卡片展示]
    F -->|3 个及以上| H[折叠为冲突组卡片]

    G --> I[用户可点击查看详情]
    H --> I

    I --> J[打开冲突二级菜单]

    J --> K[展示冲突日程列表]
    J --> L[展示 Life 调整建议]

    L --> M{用户选择}

    M -->|采纳建议| N[顺延低优先级日程]
    M -->|手动调整| O[进入编辑日程页]
    M -->|仍然保留| P[关闭菜单，保留冲突]

    N --> Q[重新生成时间轴]
    O --> Q
    P --> R[返回首页]
    Q --> R
```

冲突显示规则：

| 情况         | 首页展示           |
| ---------- | -------------- |
| 没有重合       | 普通日程卡片         |
| 2 个事件重合    | 并列卡片           |
| 3 个及以上事件重合 | 冲突组卡片          |
| 点击冲突组      | 打开二级菜单         |
| 采纳建议       | 顺延低优先级日程并刷新时间轴 |

# 7. AI 提醒卡片流程

```mermaid
flowchart TD
    A[日程数据发生变化] --> B[重新检测 AI 提醒]

    B --> C[检测时间冲突]
    C --> D[检测晚间 P0 任务]
    D --> E[检测任务结束过晚]
    E --> F[检测连续学习过久]
    F --> G[检测未完成任务]

    G --> H{是否生成提醒}

    H -->|否| I[首页不显示 AI 卡片]
    H -->|是| J[生成提醒列表]

    J --> K[按提醒优先级排序]
    K --> L[首页显示最高优先级提醒]

    L --> M{用户点击 AI 卡片}

    M -->|点击| N[打开 AI 提醒二级菜单]
    M -->|不点击| O[继续展示首页]

    N --> P[展示提醒详情]
    P --> Q[展示 Life 建议]
    Q --> R{用户选择}

    R -->|采纳建议| S[执行对应调整]
    R -->|手动调整| T[进入相关编辑页]
    R -->|稍后处理| U[关闭菜单]
    R -->|忽略| V[提醒状态改为 ignored]

    S --> W[重新生成时间轴]
    T --> W
    W --> X[重新检测 AI 提醒]
    X --> Y[返回首页]
    U --> Y
    V --> Y
```

AI 提醒优先级：

```text
时间冲突
>
晚间 P0 任务
>
任务超时
>
结束时间过晚
>
连续学习过久
>
未完成任务顺延
```

# 8. 预设模式流程

```mermaid
flowchart TD
    A[首页点击 M] --> B[进入预设模式页]

    B --> C[选择学习模式]
    B --> D[选择放松模式]
    B --> E[选择小憩模式]

    C --> F[进入模式设置页]
    D --> F
    E --> F

    F --> G[设置目标和时长]
    G --> H[点击开始]

    H --> I[进入模式进行中页面]
    I --> J[显示倒计时]
    I --> K[显示当前目标]
    I --> L[显示结束按钮]

    J --> M{模式是否结束}

    M -->|倒计时结束| N[显示结束反馈]
    M -->|用户手动结束| N

    N --> O[正向反馈文案]
    O --> P[是否顺延后续安排]

    P -->|是| Q[生成顺延建议]
    P -->|否| R[返回首页]

    Q --> S{用户确认}
    S -->|确认| T[调整后续日程]
    S -->|取消| R

    T --> U[重新生成时间轴]
    U --> R
```

预设模式 MVP 包含：

| 模式 | 默认时长  | 页面内容        |
| -- | ----- | ----------- |
| 学习 | 90 分钟 | 目标、倒计时、结束反馈 |
| 放松 | 30 分钟 | 轻量休息、结束反馈   |
| 小憩 | 20 分钟 | 倒计时、结束提醒    |

# 9. 生活管家流程

```mermaid
flowchart TD
    A[首页点击 L] --> B[进入生活管家页]

    B --> C[今日状态卡]
    B --> D[最近活动]
    B --> E[生活建议]
    B --> F[数据入口占位]

    C --> G[查看今日概览]
    D --> H[查看近期活动]
    E --> I[查看建议详情]
    F --> J[提示后续版本开放]

    I --> K{建议是否关联日程}

    K -->|是| L[跳转相关日程]
    K -->|否| M[停留当前页]

    L --> N[打开日程详情]
```

生活管家在 MVP 里不做复杂健康分析，只做：

| 内容   | MVP 状态      |
| ---- | ----------- |
| 今日状态 | 简单展示        |
| 最近活动 | 可用静态数据或本地记录 |
| 生活建议 | 轻量文案        |
| 健康数据 | 占位入口        |
| 深度分析 | 暂不做         |

# 12. 空状态流程

```mermaid
flowchart TD
    A[进入首页] --> B{今天是否有日程}

    B -->|有| C[显示今日时间轴]
```

# 13. 异常流程

```mermaid
flowchart TD
    A[用户操作] --> B{是否成功}

    B -->|成功| C[继续正常流程]
    B -->|失败| D[判断失败类型]

    D --> E[字段缺失]
    D --> F[时间非法]
    D --> G[保存失败]
    D --> H[自然语言解析失败]
    D --> I[AI 返回失败]

    E --> E1[提示补充字段]
    F --> F1[提示修改时间]
    G --> G1[提示稍后重试]
    H --> H1[进入手动补全]
    I --> I1[使用本地规则结果或提示稍后再试]

    E1 --> J[返回当前页面]
    F1 --> J
    G1 --> J
    H1 --> K[新建日程页]
    I1 --> J
```

异常处理原则：

| 情况       | 处理            |
| -------- | ------------- |
| 标题为空     | 禁止保存          |
| 时间为空     | 禁止保存          |
| 时间冲突     | 不禁止，但提醒       |
| 自然语言失败   | 进入手动补全        |
| 外部 AI 失败 | 使用本地规则或提示稍后再试 |
| 删除日程     | 必须二次确认        |
| 顺延多个日程   | 必须确认          |

# 14. MVP 最终完整用户路径

最重要的演示路径可以这样走：

```mermaid
flowchart TD
    A[打开 Life] --> B[进入首页]
    B --> C[查看今日时间轴]
    C --> D[点击 + 新建日程]
    D --> E[填写日程信息]
    E --> F[确认添加]
    F --> G[首页时间轴刷新]

    G --> H[输入：今晚10点deadline]
    H --> I[系统解析自然语言]
    I --> J[生成 P0 日程草稿]
    J --> K[用户确认添加]
    K --> L[保存日程]
    L --> M[检测晚间 P0]
    M --> N[显示 AI 提醒卡片]

    N --> O[点击 AI 提醒]
    O --> P[打开二级菜单]
    P --> Q[查看 Life 建议]
    Q --> R[采纳建议]
    R --> S[重新生成时间轴]

    S --> T[点击 M 进入预设模式]
    T --> U[选择学习模式]
    U --> V[开始倒计时]
    V --> W[结束后显示正向反馈]
    W --> X[返回首页]
```
